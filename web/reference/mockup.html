Interactive mockup · sample data

Bureau Agent

Keeps an event operationally consistent: it detects what needs attention, investigates across internal and external data, proposes valid actions, and lets organizers approve the consequences.

Two sample events share one agent and one loop: the X-IA hackathon, and a student integration weekend where the agent also plans travel and lodging under several constraints. Pick an event, open an issue, read the decision trace, then approve, edit or reject. Resolving an issue can unlock the ones that depend on it.

All names, emails, prices and times are fictional. Travel results are shown as they would come from Jinko's sandbox.

1 · Event operations

B
Bureau Agent
Organizers supervise; the agent does the legwork.

Nothing is sent, changed, booked or paid before an organizer approves it. Messages drafted by the agent end with: "Drafted with AI assistance, approved by the organizers."

2 · One loop for every event

Answering questions, reconciling payments, fixing teams and planning a trip are not separate features. They are different ways of resolving an issue in the same loop.

STATE

Event state

Participants, payments, groups, logistics, rules, deadlines, messages.

DETECT

Issues

Fixed checks find inconsistencies; the LLM reads new messages. Blocking first.

INVESTIGATE

Tools

Rules lookup, eligibility, identity matching, group checks, Jinko search, constraint checks.

APPROVE

Proposed action

With evidence, checks and confidence. The organizer approves, edits or rejects.

UPDATE

New state

The issue closes; dependent issues unlock; the loop runs again.

3 · LLM for ambiguity. Code for invariants. Humans for accountability.

LLM

Handles what is ambiguous

  • Understands messages ("I paid with my personal address")
  • Turns a plain request into hard and soft constraints
  • Chooses tools and their order
  • Decides whether to propose or to ask
  • Explains trade-offs
Fixed code

Guarantees what must hold

  • team_size ≤ 4, one team per person
  • Fee paid before the event
  • cost_per_person ≤ budget, arrival before the deadline
  • Identity score thresholds
  • Never relaxes a constraint on its own
Humans

Own the consequences

  • Anything sent outside
  • Changing a participant's status
  • Anything involving money
  • Uncertain identities
  • Exceptions to the rules
